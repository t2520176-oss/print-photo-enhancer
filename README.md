# Print Photo Enhancer

A phone-friendly web app that enhances product photos (sharpness, light, color cast, upscaling to 4K) without changing the product's shape or color. It runs entirely in the browser; photos stay on the device.

Optional Gemini AI mode: you paste your own Google AI API key in the app. The key is stored only in your browser (and only if you tick "Remember on this device"). Google bills your key per photo.

On iPhone: open the page in Safari, tap Share, then "Add to Home Screen".
